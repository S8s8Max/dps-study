# ハードウェア構成

## クラスタ構成概要

現在は1台（pi-master のみ）の構成。
ステージ1以降の分散処理体験は、同一ノード上の Docker コンテナで複数ワーカーをシミュレートする。
将来ラズパイを追加購入したときは、このファイルを更新してワーカーノードを追加する。

```
[手元PC: macOS]
      |
      | SSH / Ansible
      |
[pi-master: Raspberry Pi 3 Model B]
  ├── Docker コンテナ（ワーカーシミュレーション）
  ├── Prometheus（監視）
  └── Grafana（可視化）
```

## ノード一覧

| ホスト名 | 機種 | RAM | ストレージ | 役割 | IPアドレス | 備考 |
|----------|------|-----|-----------|------|-----------|------|
| `pi-master` | Raspberry Pi 3 Model B | 1GB | microSD（32GB以上推奨）| マスター / Ansible 実行 / 監視 | 要記入 | セットアップ後に IP を記入する |

> **IPアドレスの記入欄：** OS 初期セットアップ完了後、`hostname -I` の出力結果を上の表に記入してください。

## 管理用PC

| 項目 | 内容 |
|------|------|
| OS | macOS |
| SSH クライアント | ターミナル.app（標準搭載）|
| Ansible 実行環境 | 手元 Mac 上で実行（`brew install ansible` でインストール）|
| テキストエディタ | お好みのもの（VS Code 推奨）|

## ネットワーク

| 項目 | 値（例）| 実際の値 |
|------|--------|---------|
| サブネット | 192.168.1.0/24 | 要確認 |
| デフォルトゲートウェイ | 192.168.1.1 | 要確認 |
| DNS サーバー | 8.8.8.8 | 要確認 |
| `pi-master` の IP | 192.168.1.100 | 要記入 |

> ルーターの管理画面でラズパイの IP アドレスを固定（DHCP 予約）することを強く推奨します。
> IP が変わると SSH 接続設定や Ansible のインベントリを毎回修正する必要が生じます。

## ハードウェア仕様メモ（Raspberry Pi 3 Model B）

| 項目 | 仕様 |
|------|------|
| CPU | ARM Cortex-A53（1.2GHz、64ビット対応）|
| RAM | 1GB |
| 電源コネクタ | micro-USB（5V / 2.5A 推奨）|
| ネットワーク | 有線 LAN（100Mbps）/ Wi-Fi 2.4GHz |
| OS アーキテクチャ | arm64（aarch64）|

> ⚠️ **RAM 1GB の注意点：** Prometheus + Grafana + Docker を同時起動するとメモリが逼迫することがあります。
> 監視スタックのセットアップ時に軽量化設定を行います（`docs/stage0/08-monitoring.md` 参照）。
